Intro:
This is a prototype for first person cat cafe mockup simulator game.

Engine:
Unreal 5

MockUp Idea:
The player will manage random inventory, level up the cafe through unlocking higher tier items by spending
money and expanding the cafe, which will unlock new cats and employees. Aquarium style cozy game. 
Cat satifaction level (litter box, food bowl) determines max tip level the player can receive.
